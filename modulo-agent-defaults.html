Concepto de Asignación por Ruta

CAMBIO CLAVE

Las asignaciones ya no son a nivel de categoría, sino a nivel de ruta. Cada ruta dentro de una categoría puede tener sus propios grupos o computadoras destino. La única restricción es que todas las rutas de una misma categoría deben compartir la misma plaza — no se pueden mezclar equipos de plazas diferentes dentro de la misma categoría.

Ejemplo:

Categoría "DBF Ventas" — Plaza: TIJUANA

RutaAsignada a¿Válido?
Ruta #1 "Por Tipo" → DATA/{tipo}/{archivo}Grupo: Tijuana (PCs plaza TIJUANA)✅
Ruta #2 "Por Plaza" → DATA/{plaza}/{tipo}/{archivo}PC-CAJA-01 (plaza TIJUANA)✅
Ruta #3 "Completa" → DATA/{tipo}/{plaza}/{categoria}/{archivo}PC-ADMIN-01 (plaza NORTE)❌ Misma plaza requerida

Si se intenta asignar un equipo de plaza diferente, el sistema lo rechaza.

Validación de Plaza al Asignar

public static function validatePlaza($routeId, $assignable): bool
{
    $route = AgentDefaultCategoryRoute::findOrFail($routeId);
    $category = $route->category;

    // Obtener plaza del assignable
    if ($assignable instanceof Computer) {
        $plaza = $assignable->plaza;
    } elseif ($assignable instanceof Group) {
        // Tomar la plaza de la primera computadora del grupo
        $plaza = $assignable->computers()->first()->plaza;
    }

    // Revisar si ya hay asignaciones en la categoría
    $existingPlaza = AgentDefaultRouteAssignment::whereHas('route', fn($q) =>
        $q->where('category_id', $category->id)
    )->value('plaza');

    if ($existingPlaza && $existingPlaza !== $plaza) {
        return false; // ❌ Plaza diferente
    }

    return true; // ✅ Misma plaza o primera asignación
}
