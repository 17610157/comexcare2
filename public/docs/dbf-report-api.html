Introducción

El sistema expone dos endpoints para consultar el reporte de archivos DBF por computadora. Ambos endpoints devuelven la misma información, incluyendo los hash SHA-256 y MD5 de cada archivo.

📌 Nota: El endpoint /api/dbf-report es de acceso público. El endpoint /reportes/dbf-files/export requiere sesión iniciada y permiso dbf-files.ver.
EndpointUsoAutenticación
/api/dbf-reportAPI pública para consumo externo (JSON o CSV)❌ No requiere
/reportes/dbf-files/exportExportación desde la interfaz web (CSV)✅ Requiere sesión

Endpoint 1: API Pública /api/dbf-report

Endpoint diseñado para consumo por otros sistemas. Devuelve el listado completo de computadoras con sus archivos DBF, incluyendo hashes SHA-256 y MD5.

GET /api/dbf-report

Parámetros de filtrado

ParámetroTipoRequeridoDescripción
format json | csv No Formato de la respuesta. Por defecto: json
plaza[] string[] No Filtrar por plaza(s). Se puede repetir el parámetro para múltiples valores.
Ej: ?plaza[]=BAJAC&plaza[]=XALAPA
group_id[] int[] No Filtrar por ID(s) de grupo. Se puede repetir el parámetro.
archivo string No Filtrar por nombre de archivo (búsqueda parcial).
Ej: ?archivo=CABLISTA

Formato JSON

Cuando format=json (valor por defecto), la respuesta tiene la siguiente estructura:

{
  "data": [
    {
      "computadora":     "00099-PVSI",
      "short_key":        "00099",
      "plaza":            "BAJAC",
      "grupo":            "BAJA CALIFORNIA",
      "estado":           "online",
      "ultima_conexion":  "2026-07-01 08:53:00",
      "archivo":          "CABLISTA.DBF",
      "ruta":             "D:\\PVSI\\CABLISTA.DBF",
      "tamano_kb":        1.91,
      "ultima_modificacion": "2026-06-30 9:31:57 PM",
      "sha256":           "f0d30e8ee0b0cd49a49df5651a3376b8ee9d8a02ebad41ebfe73cdab2979329a",
      "md5":              "714DBE"
    }
  ],
  "total":              9455,
  "total_computadoras": 395
}

Formato CSV

Cuando format=csv, se descarga un archivo CSV con los encabezados:

Computadora,ShortKey,Plaza,Grupo,Estado,UltimaConexion,Archivo,Ruta,TamanoKB,UltimaModificacion,SHA256,MD5
00099-PVSI,00099,BAJAC,"BAJA CALIFORNIA",online,"2026-07-01 08:53:00",CABLISTA.DBF,"D:\PVSI\CABLISTA.DBF",1.91,"2026-06-30 9:31:57 PM",f0d30e8ee0b0cd49a49df5651a3376b8ee9d8a02ebad41ebfe73cdab2979329a,714DBE
💡 El CSV incluye BOM (Byte Order Mark) para que Excel reconozca automáticamente UTF-8. Los campos con comas van entre comillas dobles.

Endpoint 2: Exportación Web /reportes/dbf-files/export

Endpoint usado desde la interfaz web del reporte. Genera el mismo CSV pero requiere autenticación. Se accede típicamente desde el botón "Exportar" en la página del reporte.

GET /reportes/dbf-files/export
// Requiere sesión iniciada y permiso 'dbf-files.ver'

Parámetros de filtrado

Los mismos filtros que están seleccionados en la interfaz web se envían automáticamente al hacer clic en "Exportar":

ParámetroTipoDescripción
plaza[]string[]Filtrar por plaza(s)
group_id[]int[]Filtrar por ID(s) de grupo
archivostringFiltrar por nombre de archivo
_tintTimestamp (cache buster, se genera automáticamente)

Encabezados del CSV

El CSV generado tiene los siguientes encabezados:

Computadora | ShortKey | Plaza | Grupo | Estado | Última Conexión | Archivo DBF | Ruta | Tamaño (KB) | Última Modificación | SHA-256 | MD5
⚠️ Atención: Este endpoint redirige al login si no hay sesión activa. Para consumo desde otros sistemas, usa el endpoint /api/dbf-report que es público.

Ejemplos completos

🔹 Obtener todos los registros en JSON

curl "http://212.227.6.127:8000/api/dbf-report?format=json"

🔹 Filtrar por plaza

curl "http://212.227.6.127:8000/api/dbf-report?format=json&plaza[]=BAJAC&plaza[]=XALAPA"

🔹 Filtrar por grupo

curl "http://212.227.6.127:8000/api/dbf-report?format=json&group_id[]=1&group_id[]=5"

🔹 Filtrar por nombre de archivo

curl "http://212.227.6.127:8000/api/dbf-report?format=json&archivo=CABLISTA"

🔹 Combinar filtros

curl "http://212.227.6.127:8000/api/dbf-report?format=json&plaza[]=BAJAC&archivo=POS32"

🔹 Exportar a CSV (API pública)

curl "http://212.227.6.127:8000/api/dbf-report?format=csv&plaza[]=BAJAC" -o reporte.csv

🔹 Procesar con Python

import requests, json

r = requests.get("http://212.227.6.127:8000/api/dbf-report?format=json&archivo=CABLISTA")
data = r.json()

for row in data["data"]:
    print(f"{row['computadora']}: {row['sha256']}")

print(f"Total archivos: {data['total']}")

🔹 Procesar con PHP

$response = file_get_contents('http://212.227.6.127:8000/api/dbf-report?format=json');
$data = json_decode($response, true);

foreach ($data['data'] as $row) {
    echo $row['computadora'] . ': ' . $row['sha256'] . "\n";
}

echo "Total: {$data['total']}\n";

🔹 Consumir desde JavaScript (fetch)

const url = 'http://212.227.6.127:8000/api/dbf-report?format=json&plaza[]=BAJAC';

const res = await fetch(url);
const json = await res.json();

json.data.forEach(row => {
    console.log(row.computadora, row.sha256);
});

console.log(`Total: ${json.total}`);

Manejo de errores

CódigoSignificadoCausa común
200OKPetición exitosa
302RedirectEl endpoint /reportes/dbf-files/export redirige al login si no hay sesión
403ForbiddenNo tienes permiso para acceder al reporte
404Not FoundLa URL no existe. Verifica la ruta.
500Internal ErrorError del servidor. Revisa los logs.

En caso de error interno, el endpoint /api/dbf-report responderá con código HTTP 500 y un cuerpo JSON:

{
  "error": "Mensaje del error"
}
📌 Nota: Si el filtro no encuentra resultados, se devuelve un arreglo data vacío con total: 0, no es un error.
