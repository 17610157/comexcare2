1. Introduccion

1.1 Que es COMEXCARE

COMEXCARE es una plataforma web integral disenada para la gestion, monitoreo y administracion remota de equipos de computo (computadoras) distribuidos en tiendas, almacenes y centros de distribucion de COMEX a nivel nacional.

El sistema permite:

  • Monitorear el estado de cientos de computadoras en tiempo real (en linea, fuera de linea, actualizando).
  • Distribuir archivos de forma masiva: actualizaciones de agentes, archivos de precios DBF, configuraciones, comandos.
  • Recepcionar archivos desde las tiendas para su consolidacion centralizada.
  • Generar reportes detallados de ventas, metas, vales, cartera, conciliacion de archivos y mas.
  • Gestionar usuarios, roles y permisos con control de acceso granular.
  • Recibir alertas en tiempo real sobre metricas del sistema.

2. Inicio de Sesion

Para acceder al sistema, abra su navegador y navegue a la URL de COMEXCARE. Se mostrara la pantalla de inicio de sesion con un diseno retro/arcade.

Ingrese su correo electronico Escriba el correo electronico registrado en el campo "Usuario" o "Email".
Ingrese su contrasena Escriba su contrasena en el campo correspondiente.
Haga clic en "Iniciar Sesion" El sistema validara sus credenciales. Si son correctas, sera redirigido al Panel de Control.

4. Centro de Alertas

El Centro de Alertas permite monitorear metricas del sistema y recibir notificaciones automaticas cuando se superan umbrales configurados.

4.1 Panel de Alertas Activas

Muestra todas las alertas que actualmente estan activas (sin confirmar). Cada alerta incluye:

  • Severidad: Critica (rojo), Advertencia (amarillo) o Informativa (azul)
  • Mensaje: Descripcion de la alerta
  • Valor actual: Porcentaje o valor que触发 la alerta
  • Fecha y hora: Cuando se activo la alerta
  • Boton "Confirmar": Para marcar la alerta como atendida

Tambien hay un boton "Confirmar Todo" para confirmar todas las alertas activas de una vez.

4.2 Historial de Alertas

Muestra las alertas que ya fueron confirmadas/atendidas, en modo solo lectura.

4.3 Configuracion de Reglas (Administradores)

Los usuarios con permisos de administrador pueden configurar las reglas de alerta:

ParametroDescripcion
UmbralPorcentaje que activa la alerta (comparador: menor que / mayor que)
HabilitadoActivar o desactivar la regla
EnfriamientoTiempo en minutos para no repetir la misma alerta
SonidoSeleccionar un archivo de audio personalizado para la alerta

Puede subir archivos de audio (MP3, WAV, OGG, maximo 2MB) y probarlos con el boton "Probar Sonido".

5.7 Distribuciones

Envio masivo de archivos, actualizaciones o comandos a las computadoras de las tiendas.

Crear una Distribucion

Nombre y Tipo Asigne un nombre descriptivo y seleccione el tipo: Inmediata, Programada o Recurrente.
Tipo de Distribucion Seleccione: Archivo, Actualizacion o Comando.
Subir Archivo(s) Seleccione los archivos a distribuir. El sistema validara contra las listas blanca/negra automaticamente.
Seleccionar Destinatarios Elija: Todos, Por Grupo, Por Plaza o Equipos Especificos. Puede buscar computadoras por nombre.
Programacion (si aplica) Para recurrentes: frecuencia (minutos, horas, diario, semanal, mensual). Para programadas: fecha y hora.

Seguimiento en Tiempo Real

Una vez iniciada, la distribucion muestra el progreso de cada equipo objetivo:

  • Completado - Archivo enviado exitosamente
  • En Progreso - Descargando o instalando
  • Fallido - Error en la transferencia
  • Pendiente - Esperando turno
  • Offline - Equipo sin conexion

Puede reintentar equipos fallidos individualmente con el boton "Reintentar".

5.10 RBF File Hashes

Gestion de hashes MD5 de archivos RBF por plaza. El sistema usa estos hashes para verificar la integridad de los archivos en los equipos remotos.

Funcionalidades

  • Subir archivos: Seleccione uno o mas archivos y las plazas destino. El sistema calcula el MD5 sin almacenar el archivo en disco.
  • Tabla de hashes: Muestra plaza, zona, nombre del archivo, hash MD5, ruta, ultima sincronizacion y fecha de creacion.
  • Filtrar por plaza: Use el dropdown para ver solo los hashes de una plaza especifica.

5.11 Horarios por Plaza RBF

Configura los ajustes de tiempo para los archivos RBF por plaza. Estos ajustes determinan cuando se considera actualizado un archivo.

Parametros

ParametroRangoDescripcion
PlazaTextoNombre de la plaza (con autocompletado)
Meridiano0 - 23Ajuste horario en horas
Zona Horaria-12 a +14Zona horaria de la plaza
SincronizarSi/NoForzar sincronizacion inmediata al guardar
Formula: El sistema ajusta el last_modified usando: last_modified - meridiano + zona_horaria horas.

Use el boton "Sincronizar Ahora" para forzar una actualizacion inmediata de los hashes.

5.12 Listas de Archivos (Blanca/Negra)

Configura las listas de control de archivos que se aplican durante las distribuciones:

  • Lista Blanca (Whitelist): Solo se permiten enviar los archivos que esten en esta lista.
  • Lista Negra (Blacklist): Se prohíbe enviar los archivos que esten en esta lista.

Los archivos pueden coincidir por nombre exacto o por extension (ej: .exe).

7. Glosario de Terminos

TerminoDefinicion
Agente / CareAgentSoftware instalado en cada computadora de tienda que se comunica con el servidor central, ejecuta comandos y reporta el estado del equipo.
PlazaRegion geografica o area de negocio que agrupa multiples tiendas (ej: Ciudad de Mexico, Guadalajara, Monterrey).
TiendaPunto de venta o local fisico donde se encuentra la computadora monitoreada.
Short KeyIdentificador corto unico de cada computadora en el sistema.
PVSIPunto de Venta Sistemas Inteligentes - Sistema de punto de venta utilizado en las tiendas.
DBFFormato de archivo de base de datos (dBASE) utilizado para precios, listas y configuraciones.
RBFSistema de archivos de referencia para sincronizacion de precios y configuraciones.
QuickBCKSistema de respaldo rapido usado para conciliacion de archivos.
Hash MD5Firma digital de un archivo que permite verificar su integridad. Si dos archivos tienen el mismo MD5, son identicos.
DistribucionEnvio masivo de archivos, actualizaciones o comandos a multiples computadoras.
RecepcionProceso de recibir archivos desde las computadoras remotas hacia el servidor.
HeartbeatSeñal periodica que envia cada agente al servidor para indicar que esta activo y funcionando.
ValeDocumento de movimiento de mercancia (entrada/salida) registrado en el sistema.
MetaObjetivo de venta mensual asignado a una tienda o plaza.
Club ComexPrograma de lealtad de clientes de COMEX con sistema de acumulacion y redencion de puntos.
CarteraReporte de credito y abonos de clientes, incluyendo facturas, devoluciones y dias de vencimiento.
B2B / VDTBusiness to Business / Venta Directa a Trabajadores - Canales de venta especiales.
TrazabilidadCapacidad de rastrear el historial y origen de archivos a traves de multiples fuentes/disparadores.
WebSocketTecnologia de comunicacion en tiempo real que permite actualizaciones instantaneas sin recargar la pagina.
RBACRole-Based Access Control - Control de acceso basado en roles (usuarios, roles, permisos).
